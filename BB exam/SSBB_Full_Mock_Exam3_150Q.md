## Define Phase (23 Questions)

**Q1.** A Lean Six Sigma Black Belt is drafting a project charter. The section that defines the boundaries of the process, specifically detailing what is included and what is excluded, is known as the:

- A. Problem Statement
- **B. Project Scope ✓**
- C. Business Case
- D. Goal Statement

> **Answer: B** — The Project Scope defines the process boundaries, detailing what is in-scope and out-of-scope for the project team to prevent scope creep.

**Q2.** Which of the following is the primary purpose of a SIPOC diagram in the Define phase?

- **A. To provide a high-level view of the process and identify key stakeholders ✓**
- B. To perform detailed root cause analysis on process defects
- C. To calculate the baseline process sigma level
- D. To establish statistical control limits for the process

> **Answer: A** — SIPOC (Suppliers, Inputs, Process, Outputs, Customers) provides a macro-level, high-level map of the process flow to establish context and identify key stakeholders.

**Q3.** During stakeholder analysis, a stakeholder with high power but low interest is best managed by:

- A. Monitoring with minimal effort
- **B. Keeping satisfied ✓**
- C. Keeping fully informed
- D. Managing closely

> **Answer: B** — According to the Power/Interest grid, stakeholders with high power but low interest should be kept satisfied to avoid roadblocks.

**Q4.** In the Kano model, product features that are expected by default and whose absence causes extreme dissatisfaction are classified as:

- **A. Must-Be (Basic) Needs ✓**
- B. One-Dimensional (Performance) Needs
- C. Attractive (Delighter) Needs
- D. Indifferent Attributes

> **Answer: A** — Must-Be (or Basic) needs are expected by default. Their presence does not increase satisfaction, but their absence causes extreme customer dissatisfaction.

- B. Attribute data

**Q31.** A process has a mean of 50 and a standard deviation of 2. If the upper specification limit (USL) is 56, what is the Z-score for the USL?

**Q37.** A process has a USL of 100, a LSL of 70, and a process standard deviation (sigma) of 2. What is the process capability index Cp?

**Q40.** What is the key difference between Cpk and Ppk?

**Q59.** A statistical hypothesis test results in a p-value of 0.02. If the significance level (alpha) is set at 0.05, the Black Belt should:

- B. Fail to reject the null hypothesis
- C. Accept the null hypothesis as proven true

> **Answer: A** — If the p-value is less than or equal to alpha (0.05), we reject the null hypothesis, concluding that a statistically significant difference exists.

**Q60.** In hypothesis testing, a Type I error occurs when we:

- **A. Reject the null hypothesis when it is actually true (False Alarm) ✓**
- B. Fail to reject the null hypothesis when it is actually false
- C. Set the alpha level too low
- D. Conclude that no difference exists when one does

> **Answer: A** — A Type I error (producer's risk, alpha) is rejecting the null hypothesis when it is true (concluding a difference exists when it does not).

---

**Q61.** In hypothesis testing, a Type II error occurs when we:

- **B. Fail to reject the null hypothesis when it is actually false (Miss) ✓**
- C. Incorrectly calculate the degrees of freedom
- D. Select the wrong probability distribution

> **Answer: B** — A Type II error (consumer's risk, beta) is failing to reject the null hypothesis when it is false (missing an actual process change or difference).
